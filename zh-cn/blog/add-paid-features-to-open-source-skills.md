你写了一个 Skill，放在 GitHub 上，也有人在用。其中有一部分花的功夫远比其他部分多：脚本、模板、深度参考资料。你不想把 Skill 藏起来，也不想把所有东西都白送。

Frely 提供一条中间路线：**开源部分照旧免费公开，进阶部分放到付费通行证后面。** 你的仓库不需要任何改动。

## 怎么运作

把 Skill 发布到 Frely，并标出哪些文件要付费：

- **`SKILL.md` 永远免费**，让买家看得到自己买的是什么。
- **付费文件**可以是具体文件，也可以是整个文件夹，例如 `scripts/` 或 `reference/advanced.md`。
- **每种时长各定一个价格**：1 小时、8 小时、24 小时、7 天、30 天、永久，任选一到六种。

买家用一条命令安装：`frely item install <username/skill-name>`，例如 `frely item install ada/review`。ChatGPT、Codex、Claude Code 等支持 Skill 的工具都能用。通行证有效期内，安装时会一并取得付费文件；过期后，安装不再取得付费部分。`永久`通行证让买家永久保留本地副本，并包含之后的更新。

## 一句话发布

不用读文档。把下面这句话发给你平时用的 AI（它需要能在你的电脑上执行命令，例如桌面端 App、Codex 或 Claude Code）：

`请按照 https://frely.cloud/prompt/creator.md 帮我发布这个 Skill：<你的仓库地址>`

AI 会安装 Frely CLI、读取你的仓库，然后只问你三件事：

1. 哪些文件收费？默认建议脚本、模板和深度参考资料。
2. 每种时长定什么价？
3. 要不要提供`永久`通行证？

剩下的它自己完成，最后把条目 ID 和安装命令交给你。

## 发布前要知道

- **买了的人能看到付费部分。** Skill 会安装在买家自己的设备上，所以免费部分所有人可见，付费部分对持有通行证的人可见。如果内容必须保密，请改成托管 Agent 发布：使用者拿到结果，看不到提示词。
- **先看许可证。** 如果仓库的许可证禁止再分发，就不要发布。来源链接会作为署名显示，Frely 不核验仓库所有权。
- **大小限制。** 打包后的 Skill 不超过 256 KiB，64 个文件，单文件 64 KiB，总计 128 KiB。
- **你得到的是 Frely Credit。** 使用费冻结 30 天后计入你的 Frely Credit，只能在 Frely 站内消费，不能提现或转让。平台会从每笔销售中扣除服务费，设置价格时页面上能看到。
- **免费账号可以发布 1 个条目。**

## 更新与下架

发布新版本时，用同一个 slug 再发布一次；下架时把它标为未发布。你的 GitHub 仓库不会被动，开源版本一直留在原处。

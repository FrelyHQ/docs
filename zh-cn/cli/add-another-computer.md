# 如何添加另一台电脑？

在新电脑上运行安装命令，或者让已连接到 FrelyMCP 的 ChatGPT 或 Claude 帮你添加电脑：`list_devices` 会返回一条安装命令。你也可以在 Frely App 的 My Devices（我的设备）中创建一台电脑。凡是你运行过 `frely link on` 的电脑，都会出现在同一个 MCP URL 下，并且所有客户端都能共享每台电脑的工作区和正在运行的进程。

Related: [Frely App（My Devices）](https://frely.cloud/app/) · [FrelyMCP 端点](https://mcp.frely.cloud/mcp)

# 如何将 ChatGPT 或 Claude 连接到我的电脑？

首先在电脑上运行 `frely link on`；它会输出 MCP URL。FrelyMCP 是您整个账号共用的一个地址：https://mcp.frely.cloud/mcp。在 ChatGPT 或 Claude 中使用该 URL 添加自定义连接器，然后登录 Frely 并批准该客户端。要验证是否成功，可以让客户端列出您工作区中的顶层名称。

Related: [FrelyMCP 端点](https://mcp.frely.cloud/mcp) · [安装页面](https://cli.frely.cloud/#install) · [README](https://github.com/FrelyHQ/frely-cli/blob/main/README.md)

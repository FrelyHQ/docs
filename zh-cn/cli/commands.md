# CLI 有哪些命令？

主要命令包括：`frely link on|status|stop|off|auto-update`、`frely link workspace list|add|remove`、`frely link local list|add|remove`、`frely doctor`、`frely update`、`frely login`、`frely logout`、`frely uninstall`、`frely agent install|run|result|runs|cancel|status|remove`、`frely item install|update|trust`、`frely provider share|list` 和 `frely api list|describe|call`。不带子命令直接运行任意命令组（例如 `frely link`）即可查看它提供的功能；`frely help --agent --json` 会输出完整的机器可读契约。

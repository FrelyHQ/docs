# 什么是 Frely CLI？

Frely CLI（即 `frely` 命令）可以将你选定的一台计算机变成可供 AI Agent 从任何地方进行操作的设备。ChatGPT、Claude、Codex 以及其他 MCP 客户端通过 FrelyMCP 连接，并使用你允许的文件夹中的文件、shell 命令和进程。该计算机主动向外连接到 Frely，因此你无需开放任何端口。它同时也是你的 Frely 账户的命令行工具。

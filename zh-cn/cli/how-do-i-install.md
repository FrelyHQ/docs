# 如何安装 Frely CLI？

在 macOS 或 Linux 上运行 `curl -fsSL https://frely.cloud/start.sh | sh`。在 Windows 上，请运行安装页面中显示的 PowerShell 命令。该脚本会安装最新版的 `frely`，然后运行 `frely link on`，此命令会打开浏览器供你登录（新账号可在同一页面注册），要求你批准该设备，并打印你的 MCP URL。之后你可以随时再次运行该命令进行更新。

Related: [安装页面](https://cli.frely.cloud/#install) · [start.sh](https://frely.cloud/start.sh) · [start.ps1 (Windows)](https://frely.cloud/start.ps1)

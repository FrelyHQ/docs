# 在 Frely 上创作与销售

## 我可以发布什么？
<!-- id: what-sell -->

一条你有权发布的提示词、Skill、Agent 或工作流。请定义它的任务、输入、输出和限制。你出售的是对该能力的访问权，你的核心提示词、代码和工作流不会交付给买家。

Related: [定价](https://frely.cloud/pricing/) · [安全与数据](https://frely.cloud/security/)

## 我发布的条目会显示在哪里？
<!-- id: where-listed -->

新建的 Skill、MCP 或 Agent 会显示在你的个人主页（`frely.cloud/@<username>`）和你的资料库中。公开的 Store 只列出 Frely 精选的产品，因此除非 Frely 收录，你的条目不会出现在那里。其他人通过你的个人主页、分享链接或你授予的通行证访问你的条目。在条目上打开 Visibility（可见性），可以设为仅自己可见、显示在你的个人主页上，或展示给你选择的 Teams（团队）。

Related: [定价](https://frely.cloud/pricing/)

## 托管 Agent 与下载安装类条目有什么区别？
<!-- id: hosted-vs-install -->

托管 Agent 在 Frely 上运行，买家通过 Frely 使用它，因此你的私密内容始终保留在你自己手里。下载安装类提示词或 Skill 会把文件交付到买家自己的设备上；免费部分对每位安装者都可见，且 Frely 无法撤回已安装的副本。必须保持私密的内容应当以托管 Agent 的形式发布在付费的 Creator 套餐上。

Related: [服务条款](https://frely.cloud/terms/)

API tools: `skills.list`, `agents.list`

## 我可以发布多少个服务？
<!-- id: plan-limits -->

Creator 最多允许发布 <!-- fact:creator.publishedModelLimit -->3<!-- /fact --> 个，Creator Plus 最多允许发布 <!-- fact:creator_plus.publishedModelLimit -->100<!-- /fact --> 个。

Related: [定价](https://frely.cloud/pricing/)

API tools: `creator.subscription`

## 我没有看到发布或产品入口。
<!-- id: cannot-publish -->

仅登录并不会授予发布权限。请检查你的套餐是否处于生效状态，以及你是否满足发布资格和商业条款。

Related: [服务条款](https://frely.cloud/terms/)

## 销售收入等同于利润或可提现余额吗？
<!-- id: revenue -->

不是。创作者需要承担模型和服务的运行成本，收入并不自动等同于利润或你可以提现的余额。结算遵循服务条款进行。

Related: [服务条款](https://frely.cloud/terms/)

## 我需要拥有哪些权利？
<!-- id: rights -->

你必须持有分发所发布文件和内容的权利，并在需要时注明原始来源。不允许发布侵犯他人权利的内容。

Related: [服务条款](https://frely.cloud/terms/)

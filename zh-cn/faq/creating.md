# 在 Frely 上创建与销售

## 我可以发布什么？
<!-- id: what-sell -->

你有权发布的 Prompt、Skill、Agent 或工作流。为它定义任务、输入、输出和限制。你出售的是对该能力的访问权，你的核心提示词、代码和工作流不会交付给买家。

Related: [定价](https://frely.cloud/pricing/) · [安全与数据](https://frely.cloud/security/)

## 托管 Agent 与下载安装型商品有什么区别？
<!-- id: hosted-vs-install -->

托管 Agent 在 Frely 上运行，买家通过 Frely 使用它，你的私密内容仍然留在你手里。下载安装型 Prompt 或 Skill 会把文件交付到买家自己的设备；免费部分对每个安装者都可见，而且 Frely 无法撤回已安装的副本。必须保持私密的内容，应以付费 Creator 套餐上的托管 Agent 形式发布。

Related: [服务条款](https://frely.cloud/terms/)

API tools: `skills.list`, `agents.list`

## 我可以发布多少个服务？
<!-- id: plan-limits -->

Creator 最多允许 <!-- fact:creator.publishedModelLimit -->3<!-- /fact --> 个，Creator Plus 最多允许 <!-- fact:creator_plus.publishedModelLimit -->100<!-- /fact --> 个。

Related: [定价](https://frely.cloud/pricing/)

API tools: `creator.subscription`

## 我没有发布或商品的入口。
<!-- id: cannot-publish -->

仅登录不会获得发布权限。请确认你的套餐处于生效状态，并且你满足发布资格和商业条款。

Related: [服务条款](https://frely.cloud/terms/)

## 销售收入等于利润或可提现余额吗？
<!-- id: revenue -->

不等于。创作者需要承担模型和服务的运行成本，收入不会自动成为利润，也不是可以提现的余额。结算遵循服务条款。

Related: [服务条款](https://frely.cloud/terms/)

## 我需要哪些权利？
<!-- id: rights -->

你必须拥有发布这些文件和内容并进行分发的权利，并在必要时注明原始来源。不允许发布侵犯他人权利的内容。

Related: [服务条款](https://frely.cloud/terms/)

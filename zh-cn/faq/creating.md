# 在 Frely 上创作和售卖

## 我可以发布什么？
<!-- id: what-sell -->

你有权发布的 Prompt、Skill、Agent 或工作流。定义好它的任务、输入、输出和限制。你售卖的是对这项能力的访问权，你的核心提示词、代码和工作流不会交给买家。

Related: [定价](https://frely.cloud/pricing/) · [安全与数据](https://frely.cloud/security/)

## 托管 Agent 和下载安装型商品有什么区别？
<!-- id: hosted-vs-install -->

托管 Agent 运行在 Frely 上，买家通过 Frely 使用，你的私密内容留在你手里。下载安装型 Prompt 或 Skill 会把文件交付到买家自己的设备；免费部分对每个安装者都可见，Frely 无法撤回已安装的副本。必须保密的内容应以付费 Creator 套餐发布为托管 Agent。

Related: [服务条款](https://frely.cloud/terms/)

API tools: `skills.list`, `agents.list`

## 我最多能发布多少个服务？
<!-- id: plan-limits -->

Creator 最多 <!-- fact:creator.publishedModelLimit -->3<!-- /fact --> 个，Creator Plus 最多 <!-- fact:creator_plus.publishedModelLimit -->100<!-- /fact --> 个。

Related: [定价](https://frely.cloud/pricing/)

API tools: `creator.subscription`

## 我没有发布入口或商品入口。
<!-- id: cannot-publish -->

仅登录不会自动开放发布权限。请确认你的套餐处于生效状态，并满足发布资格和商业条款。

Related: [服务条款](https://frely.cloud/terms/)

## 销售收入等于利润或可提现余额吗？
<!-- id: revenue -->

不等于。创作者需要自行承担模型和服务的运行成本，收入不会自动成为利润，也不是可提现的余额。结算按服务条款执行。

Related: [服务条款](https://frely.cloud/terms/)

## 我需要拥有什么权利？
<!-- id: rights -->

你必须拥有所发布文件和内容的分发权利，并在必要时注明原始来源。不允许发布侵犯他人权利的内容。

Related: [服务条款](https://frely.cloud/terms/)

# 账户与登录

## 如何获得 Frely 账户？
<!-- id: create-account -->

打开 Frely 工作台，按登录流程操作。新账户使用网站提供的注册或 Team 邀请入口。注册目前为邀请制，可在抢先体验页面申请，Frely 会把邀请发送到你的邮箱。

Related: [申请抢先体验](https://frely.cloud/early-access/)

## 有年龄要求吗？
<!-- id: age -->

有。本服务面向 18 周岁及以上的人群。你必须提供准确的账户信息，并妥善保管你的凭据、API Key、设备和会话。

Related: [服务条款](https://frely.cloud/terms/)

## 我无法登录，该怎么办？
<!-- id: cannot-sign-in -->

使用登录页面的反馈入口、密码找回流程或你的 Team 邀请。Frely 网站绝不会要求你通过邮件发送密码。如果这些方法都无效，请发邮件联系支持，附上你的账户邮箱或用户名，以及问题发生的时间（注明时区）。

Related: [联系支持](https://frely.cloud/support/)

Console: [账户安全](https://frely.cloud/user/account/security)

## 我的账户或 API Key 可能已经泄露。
<!-- id: compromise -->

立即在工作台中撤销该 API Key，并发邮件联系支持。使用你的账户或 API 凭据进行的活动由你负责，因此疑似泄露必须上报。

Related: [联系支持](https://frely.cloud/support/) · [服务条款](https://frely.cloud/terms/)

Console: [你的 API Key](https://frely.cloud/user/account/keys)

API tools: `keys.list`, `keys.set_status`, `keys.revoke`

## 我可以关闭账户或删除我的数据吗？
<!-- id: close-account -->

发邮件联系支持并提出请求。Frely 可能要求提供信息以验证是你本人。因支付、会计、安全、反欺诈、争议、法律或审计原因必须保留的记录，不会因请求而删除。

Related: [联系支持](https://frely.cloud/support/) · [隐私政策](https://frely.cloud/privacy/)

# 账户与登录

## 如何获得 Frely 账户？
<!-- id: create-account -->

打开用户控制台，按登录流程操作。新账户通过网站提供的注册入口或 Team 邀请创建。注册目前采用邀请制，请在抢先体验页面申请，Frely 会把邀请发送到你的邮箱。

Related: [申请抢先体验](https://frely.cloud/early-access/)

## 是否有年龄要求？
<!-- id: age -->

有。本服务面向年满 18 周岁的人群。你必须提供准确的账户信息，并保管好自己的凭据、API Key、设备和会话。

Related: [服务条款](https://frely.cloud/terms/)

## 无法登录怎么办？
<!-- id: cannot-sign-in -->

使用登录页的反馈入口、找回密码流程或你的 Team 邀请。Frely 网站绝不会要求你通过邮件发送密码。如果都不行，请发邮件联系支持，附上账户邮箱或用户名，以及问题发生的时间（含你的时区）。

Related: [联系支持](https://frely.cloud/support/)

Console: [账户安全](https://frely.cloud/user/account/security)

## 我的账户或 API Key 疑似泄露了。
<!-- id: compromise -->

立即在控制台吊销该 API Key，并发邮件联系支持。使用你的账户或 API 凭据产生的操作由你负责，因此疑似泄露必须及时报告。

Related: [联系支持](https://frely.cloud/support/) · [服务条款](https://frely.cloud/terms/)

Console: [你的 API Key](https://frely.cloud/user/account/keys)

API tools: `keys.list`, `keys.set_status`, `keys.revoke`

## 如何注销账户或删除我的数据？
<!-- id: close-account -->

发邮件向支持提出申请。Frely 可能要求提供信息以确认是你本人。因支付、会计、安全、反欺诈、争议、法律或审计原因必须保留的记录，不会因申请而删除。

Related: [联系支持](https://frely.cloud/support/) · [隐私政策](https://frely.cloud/privacy/)

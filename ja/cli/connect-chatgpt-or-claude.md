# ChatGPT や Claude をパソコンに接続するにはどうすればよいですか？

まず、パソコンで `frely link on` を実行すると、MCP の URL が表示されます。FrelyMCP はアカウント全体で共通の 1 つのアドレスです： https://mcp.frely.cloud/mcp。ChatGPT または Claude で、その URL を指定して Add custom connector(カスタムコネクターを追加)からコネクターを追加し、Frely にサインインしてクライアントを承認します。動作を確認するには、クライアントにワークスペースの最上位の名前を一覧表示するよう依頼してください。

Related: [FrelyMCP エンドポイント](https://mcp.frely.cloud/mcp) · [インストールページ](https://cli.frely.cloud/#install) · [README](https://github.com/FrelyHQ/frely-cli/blob/main/README.md)

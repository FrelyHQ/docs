# Frely CLIはどのようにインストールしますか？

macOSまたはLinuxでは、`curl -fsSL https://frely.cloud/start.sh | sh` を実行してください。Windowsでは、インストールページに表示されているPowerShellコマンドを実行してください。このスクリプトは最新の `frely` をインストールし、続いて `frely link on` を実行します。これにより、サインインのためにブラウザが開き（新規アカウントは同じページで登録できます）、デバイスの承認を求めた後、あなたのMCP URLが表示されます。更新したいときは、いつでももう一度実行してください。

Related: [インストールページ](https://cli.frely.cloud/#install) · [start.sh](https://frely.cloud/start.sh) · [start.ps1 (Windows)](https://frely.cloud/start.ps1)

# CLIにはどのコマンドがありますか？

主なコマンドは次のとおりです：`frely link on|status|stop|off|auto-update`、`frely link workspace list|add|remove`、`frely link local list|add|remove`、`frely doctor`、`frely self update`、`frely login`、`frely logout`、`frely self uninstall`、`frely item install|update|trust|call|status|remove`、`frely result|result list|result cancel`、`frely service share|list|stop|remove`、`frely agent list|status|run|setup|start|stop|logs|remove|key`、`frely provider list`、`frely api list|describe|call`。サブコマンドを付けずにコマンドグループを実行すると（例：`frely link`）、そのグループで利用できるコマンドを確認できます。`frely help --agent --json` を実行すると、機械可読なコントラクトの全容が出力されます。

# 別のコンピューターを追加するにはどうすればよいですか？

新しいコンピューターでインストールコマンドを実行するか、FrelyMCP に接続した ChatGPT や Claude にコンピューターの追加を依頼してください。`list_devices` がインストールコマンドを返します。Frely App の My Devices から作成することもできます。`frely link on` を実行したすべてのコンピューターは同じ MCP URL の背後に表示され、すべてのクライアントが各コンピューターのワークスペースと実行中のプロセスを共有します。

Related: [Frely App (My Devices)](https://frely.cloud/app/) · [FrelyMCP エンドポイント](https://mcp.frely.cloud/mcp)

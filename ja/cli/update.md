# Frely CLI の更新方法

`frely update` を実行してください。このコマンドはログイン情報、デバイス、URL、ワークスペースを保持したまま、ダウングレードを行わず、バックグラウンドサービスを一時停止し、プログラムを検証してから置き換え、サービスを再起動します。Windows では、ローカルターミナルで実行する PowerShell コマンドが表示されます。https://frely.cloud/start.sh を再度実行しても、サービスが更新・再起動されます。

Related: [セルフアップデートのドキュメント](https://github.com/FrelyHQ/frely-cli/blob/main/docs/self-update.md) · [start.sh](https://frely.cloud/start.sh)

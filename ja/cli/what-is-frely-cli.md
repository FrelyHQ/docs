# Frely CLI とは？

Frely CLI（`frely` コマンド）は、選択したコンピューターを、AI エージェントがどこからでも作業できるデバイスに変えます。ChatGPT、Claude、Codex などの MCP クライアントは FrelyMCP を通じて接続し、許可したフォルダー内のファイル、シェルコマンド、プロセスを利用できます。コンピューターは外に向かって Frely に接続するため、ポートを開放する必要はありません。また、Frely アカウント用のコマンドラインとしても機能します。

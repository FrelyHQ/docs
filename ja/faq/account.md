# アカウントとログイン

## Frely アカウントを取得するには？
<!-- id: create-account -->

Frely ワークスペースを開き、ログインフローを利用します。新規アカウントは、サイトが用意する登録または Team の招待の入口から始めます。サインアップは招待制のため、アーリーアクセスページから申請すると、Frely が招待をメールで送ります。

Related: [アーリーアクセスを申し込む](https://frely.cloud/early-access/)

## 年齢の条件はありますか？
<!-- id: age -->

はい。本サービスは 18 歳以上の方を対象としています。正確なアカウント情報を提供し、認証情報、API キー、デバイス、セッションを管理する責任があります。

Related: [利用規約](https://frely.cloud/terms/)

## ログインできません。どうすればいいですか？
<!-- id: cannot-sign-in -->

ログインページのフィードバック、パスワード復旧フロー、または Team の招待を利用します。Frely のウェブサイトがメールでパスワードの送信を求めることはありません。いずれも解決しない場合は、アカウントのメールアドレスまたはユーザー名と、発生時刻（タイムゾーン込み）を添えてサポートにメールしてください。

Related: [サポートに連絡](https://frely.cloud/support/)

Console: [アカウントのセキュリティ](https://frely.cloud/user/account/security)

## アカウントまたは API キーが漏洩した可能性があります。
<!-- id: compromise -->

ワークスペースで API キーを失効させ、直ちにサポートにメールしてください。アカウントや API 認証情報を使って行われた操作の責任は利用者にあるため、漏洩の疑いは報告が必要です。

Related: [サポートに連絡](https://frely.cloud/support/) · [利用規約](https://frely.cloud/terms/)

Console: [あなたの API キー](https://frely.cloud/user/account/keys)

API tools: `keys.list`, `keys.set_status`, `keys.revoke`

## アカウントを解約したりデータを削除したりできますか？
<!-- id: close-account -->

サポートにメールでリクエストを送ってください。Frely は本人確認のため情報を求める場合があります。支払い、会計、セキュリティ、不正防止、紛争、法的または監査の理由で Frely が保管しなければならない記録は、リクエストしても削除されません。

Related: [サポートに連絡](https://frely.cloud/support/) · [プライバシーポリシー](https://frely.cloud/privacy/)

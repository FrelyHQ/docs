# FrelyMCP

FrelyMCP は、あなたの Frely アカウント用の MCP サーバーです。一度接続すれば、AI アプリから自分のコンピューター、有効にしたクラウドツール、そしてモデルや AI エージェントにアクセスできます。サインインは OAuth で行うため、API Key をアプリに貼り付ける必要はありません。

## できること
<!-- id: what -->

ローカル： アカウントにリンクされたコンピューターを一覧表示し、ワークスペース内のファイルの読み取り、編集、コマンドの実行、Web ページの取得を行います。ローカルファイルの読み書きはその一部にすぎません。クラウド： この接続に対して有効にしたクラウド MCP サーバーを、デバイスなしで利用できます。モデルとエージェント： 利用できるモデルやエージェントを一覧表示し、MCP での利用をオン/オフにし、AI アプリの中から問い合わせることができます。自分のエージェントを接続することもでき、モデルと同じように動作します。利用料金は Frely アカウントに請求されます。

## 始める前に
<!-- id: before -->

Frely アカウントが必要です(frely.cloud でサインインしてください)。デバイスツールを使うには、コンピューターに Frely CLI をインストールしてリンクします。モデル、エージェント、クラウドツールはデバイスなしで動作します。

```sh
curl -fsSL https://frely.cloud/install.sh | sh
frely login
frely mcp start
```

## AI アプリを接続する
<!-- id: connect -->

このアドレスを MCP サーバー URL として指定し、OAuth を選択してください。認証ヘッダーは追加しないでください。

```sh
https://mcp.frely.cloud/mcp
```

## Claude
<!-- id: claude -->

Claude で Settings(設定)を開き、Connectors(コネクタ)に進み、Add custom connector(カスタムコネクタを追加)を選択します。名前に FrelyMCP と入力し、上記のアドレスを貼り付けます。Connect(接続)を選び、Frely にサインインしてアクセスを承認してください。Claude Code の場合は、claude mcp add --transport http frelymcp https://mcp.frely.cloud/mcp を実行し、続いて /mcp でサインインします。

## ChatGPT
<!-- id: chatgpt -->

ChatGPT で Settings を開き、アプリとコネクタのセクションに進みます。新しいコネクタを作成し、上記のアドレスを貼り付け、OAuth を選択して Frely にサインインしてください。カスタムコネクタには、ChatGPT のプランによって開発者モードが必要な場合があります。

## 設定ファイルでインストールする
<!-- id: config -->

WorkBuddy など一部の AI エージェントは、コネクタ画面の代わりに設定ファイルで MCP サーバーを追加します。エージェントの MCP 設定ファイル内の mcpServers オブジェクトに、このエントリを追加してください(すでにあるサーバーはそのまま残します)。その後、エージェントを再起動し、求められたら Frely のサインインと承認を完了してください。エージェントが url フィールドに対応していない場合は、同じアドレスを使ってリモートまたは HTTP サーバーのオプションを利用してください。

```json
{
  "mcpServers": {
    "frely": {
      "url": "https://mcp.frely.cloud/mcp"
    }
  }
}
```

## ツール
<!-- id: tools -->

AI アプリから呼び出せるツール：

| ツール | 説明 |
| --- | --- |
| `list_devices` | リンクされたコンピューターとそのワークスペース、オンラインかどうかを表示します。最初に呼び出してください。 |
| `read` | ワークスペース内のファイルやフォルダを読み取ります。 |
| `edit_file` | ワークスペース内のファイルを作成または変更します。 |
| `process` | デバイス上でコマンドを実行し、その出力を返します。 |
| `web_fetch` | デバイスから Web ページを取得します。 |
| `request_permission / confirm_permission` | 既定のサンドボックスの外側へのアクセス(たとえば ~/.ssh)の承認を求めます。Frely サイト上でコードを使って承認します。 |
| `models_list / models_set / models_invoke` | モデルとエージェントを一覧表示し、MCP での利用をオン/オフにし、問い合わせます。有効にしたものはそれぞれ <model>__invoke としても表示されます。 |
| `<mcp>__<tool>` | この接続に対して有効にしたクラウド MCP サーバーのツールです。クラウドで実行され、デバイスは不要です。 |
| `local_mcp_list / local_mcp_call` | デバイス上で動作している MCP サーバーがあれば、それにアクセスします。 |
| `frely_list / frely_call` | Frely アカウントを管理します： API Key、Credit、プラン、注文、Creator のアイテムなど。クラウドで実行され、デバイスは不要です。新しい接続では、Frely サイトで許可を追加するまで読み取りのみとなる場合があります。お金の移動や認証情報の変更を伴う操作には毎回あなたの承認が必要で、支払いの際には支払いページが開きます。 |
| `store` | Frely Store(サブスクリプション、プラン、Credit、拡張機能、Skills、サービス)をカードとして表示します。カードに対応していないアプリでは表として表示します。各 Buy リンクは、その製品の Frely サイト上のページを開き、そこで支払いを行います。 |

## 安全性と承認
<!-- id: safety -->

コマンドはコンピューター上のサンドボックスで実行され、~/.ssh や ~/.aws などの認証情報フォルダはブロックされます。また、ツールが触れるのは登録済みのワークスペースだけです。タスクにそれ以上の権限が必要な場合、AI アプリは request_permission で要求しなければなりません。承認は Frely サイト上で行い、有効期間を選択でき、後で取り消すこともできます。AI アプリが自分の要求を承認することはできません。

## あなたのデータ
<!-- id: data -->

デバイスツールの呼び出し(read、edit_file、process、web_fetch、ローカル MCP)はあなた自身のコンピューターに中継され、FrelyMCP は OAuth のサインイン記録のみを保持します。モデルやエージェントへの呼び出しは Frely ゲートウェイを経由します。Request Capture は、これらのリクエストとレスポンスの内容を一定期間保持することがあり、選択したモデルプロバイダーは回答に必要なリクエストデータを受け取ります。詳細はプライバシーポリシーの第 4 条および第 6 条に記載されています。Frely Credit は譲渡できません。モデルの呼び出しに対する計上は、あなた自身の Credit に対してのみ行われます。

## うまく動かないとき
<!-- id: help -->

list_devices でデバイスが表示されない場合は、コンピューター上で frely mcp start を実行し、CLI が同じ Frely アカウントでサインインしているか確認してください。デバイスがオフラインの場合は、コンピューターの電源を入れて同じコマンドを実行してください。その他のご質問は support@frely.cloud まで。

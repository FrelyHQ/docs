あなたはSkillを書き、GitHubに置き、人々が使っています。その中には、他の部分よりはるかに多くの労力をかけたものがあります。スクリプト、テンプレート、詳細なリファレンスファイルです。Skillを隠したいわけでもなく、かといってすべてを渡してしまいたいわけでもありません。

Frelyには、その中間となる道が用意されています。**オープンソースの部分は無料かつ公開のままです。高度な部分は有料パスの後ろに置かれます。**リポジトリは変更されません。

## 仕組み

SkillをFrelyに公開し、どのファイルが有料かを指定します：

- **`SKILL.md` は常に無料**です。そのため、購入者は何を手に入れるのかを事前に確認できます。
- **有料ファイル**は、特定のファイルまたはフォルダ全体です。たとえば `scripts/` や `reference/advanced.md` です。
- **パスの期間ごとに価格を設定します**:1時間、8時間、24時間、7日、30日、無期限(forever)から選べます。1つだけでも、6つすべてでも提供できます。

購入者は1つのコマンドでインストールします：`frely item install <item-id>`。ChatGPT、Codex、Claude Code など、Skillを使うツールで動作します。パスが有効な間は、有料ファイルもSkillと一緒に取得されます。パスが期限切れになると、そのインストールは有料部分の取得を停止します。`forever` パスを購入すると、購入者はローカルコピーを永久に保持でき、以降のアップデートも含まれます。

## メッセージ1つで公開する

ドキュメントを読む必要はありません。すでに使っているAIに次のメッセージを送ってください(デスクトップアプリ、Codex、Claude Code のように、あなたのコンピュータ上でコマンドを実行できるAIが必要です):

`Follow https://frely.cloud/prompt/creator.md and publish this Skill: <your repository URL>`

AIはFrely CLIをインストールし、リポジトリを読み込んだうえで、ちょうど3つのことを尋ねます：

1. どのファイルを有料にするか。デフォルトでは、スクリプト、テンプレート、詳細なリファレンスファイルが提案されます。
2. パスの期間ごとの価格はいくらにするか。
3. `forever` パスを提供するか。

残りの作業はAIが行い、アイテムIDとインストールコマンドを教えてくれます。

## 公開前に知っておくこと

- **有料部分は、購入した人には見えます。**Skillは購入者自身のデバイスにインストールされるため、無料部分は全員に見え、有料部分はパスを持つ人全員に見えます。コンテンツを非公開のままにする必要がある場合は、代わりにホスト型Agentとして公開してください。ホスト型Agentでは、ユーザーは結果を受け取りますが、プロンプトを見ることはありません。
- **ライセンスを確認してください。**リポジトリのライセンスが再配布を禁じている場合は、公開しないでください。ソースURLは帰属表示として示されますが、Frelyはリポジトリの所有権を確認しません。
- **サイズ制限。**zip圧縮したSkillは、最大256 KiB、最大64ファイル、1ファイルあたり64 KiB、合計128 KiBまでです。
- **受け取るのはFrely Creditであり、現金ではありません。**利用料は30日間保留された後、Frely Creditに加算され、Frely内で使うことができます。出金や譲渡はできません。Frelyは販売ごとにプラットフォーム手数料を受け取ります。手数料は価格を設定するページに表示されます。
- **無料アカウントで公開できるアイテムは1つです。**

## 更新と公開の取り下げ

新しいバージョンをリリースするには、同じスラッグで再度公開します。公開を取り下げるには、非公開(unpublished)のマークを付けます。GitHubリポジトリには一切触れないため、オープンソース版はこれまで通りの場所にそのまま残ります。

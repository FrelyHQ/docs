# What can the AI do on my computer?

Through FrelyMCP the AI can use `list_devices` (your computers and whether each is online), `read` (list, read, search and find files in the workspace), `edit_file` (write whole files or edit lines in one step), `process` (run shell commands or manage long-running processes) and `web_fetch` (read public web pages). Device tools take a `device` argument and run on that computer. The AI client's own shell still runs where the client runs, so ask it to use the Frely tools for work on your computer.

# 在 Frely 上創作與銷售

## 我可以發佈甚麼？
<!-- id: what-sell -->

任何你有權發佈的提示詞、Skill、Agent 或工作流程。請界定其任務、輸入、輸出及限制。你售賣的是使用該功能的權限，而你的核心提示詞、程式碼及工作流程並不會交到買家手上。

Related: [定價](https://frely.cloud/pricing/) · [安全與資料](https://frely.cloud/security/)

## 我發佈的項目會在哪裏顯示？
<!-- id: where-listed -->

新建的 Skill、MCP 或 Agent 會顯示在你的個人檔案頁面(`frely.cloud/@<username>`)及你的資料庫中。公開的 Store 只會列出 Frely 精選的產品，因此除非 Frely 主動收錄，否則你的項目不會在那裏出現。其他人可透過你的個人檔案頁面、分享連結，或你發給他們的通行證來存取你的項目。在項目上開啟 Visibility(可見性)，即可將其設為僅自己可見、顯示於個人檔案頁面，或只向你選擇的團隊顯示。

Related: [定價](https://frely.cloud/pricing/)

## 託管式 Agent 與下載安裝式項目有甚麼分別？
<!-- id: hosted-vs-install -->

託管式 Agent 在 Frely 上運行，買家透過 Frely 使用，因此你的私人內容仍保留在你手中。下載安裝式的提示詞或 Skill 會把其檔案傳送到買家自己的裝置；免費部分對任何安裝的人都可見，而且 Frely 無法回收已安裝的副本。必須保密的內容應以付費 Creator 方案上的託管式 Agent 形式發佈。

Related: [服務條款](https://frely.cloud/terms/)

API tools: `skills.list`, `agents.list`

## 我可以發佈多少個服務？
<!-- id: plan-limits -->

Creator 最多可發佈 <!-- fact:creator.publishedModelLimit -->3<!-- /fact --> 個服務，Creator Plus 則最多可發佈 <!-- fact:creator_plus.publishedModelLimit -->100<!-- /fact --> 個。

Related: [定價](https://frely.cloud/pricing/)

API tools: `creator.subscription`

## 我找不到發佈或產品入口。
<!-- id: cannot-publish -->

僅僅登入並不代表可以發佈。請確認你的方案仍然生效，而你亦符合發佈資格及商業條款。

Related: [服務條款](https://frely.cloud/terms/)

## 銷售收益是否等同於利潤或可提取的餘額？
<!-- id: revenue -->

不是。創作者須自行承擔模型及服務的營運成本，收益亦不會自動成為利潤或可提取的餘額。結算按服務條款處理。

Related: [服務條款](https://frely.cloud/terms/)

## 我需要具備甚麼權利？
<!-- id: rights -->

你必須持有分發你所發佈的檔案及內容的權利，並在有需要時註明原始來源。侵犯他人權利的內容一律不獲允許。

Related: [服務條款](https://frely.cloud/terms/)

# 在 Frely 上創作及銷售

## 我可以發佈甚麼？
<!-- id: what-sell -->

任何你有權發佈的提示（Prompt）、Skill、Agent 或工作流程。請界定其任務、輸入、輸出及限制。你售賣的是該能力的存取權，而你的核心提示、程式碼及工作流程不會交予買家。

Related: [定價](https://frely.cloud/pricing/) · [安全性與資料](https://frely.cloud/security/)

## 託管 Agent 與下載安裝式項目有甚麼分別？
<!-- id: hosted-vs-install -->

託管 Agent 在 Frely 上執行，買家透過 Frely 使用，因此你的私人內容仍由你保留。下載安裝式提示或 Skill 則會將其檔案傳送至買家自己的裝置；免費部分會向所有安裝的人公開，而 Frely 無法取回已安裝的副本。必須保持私密的內容，應以託管 Agent 形式發佈於付費 Creator 方案上。

Related: [服務條款](https://frely.cloud/terms/)

API tools: `skills.list`, `agents.list`

## 我可以發佈多少個服務？
<!-- id: plan-limits -->

Creator 允許最多 <!-- fact:creator.publishedModelLimit -->3<!-- /fact --> 個，而 Creator Plus 則最多 <!-- fact:creator_plus.publishedModelLimit -->100<!-- /fact --> 個。

Related: [定價](https://frely.cloud/pricing/)

API tools: `creator.subscription`

## 我沒有發佈或產品入口。
<!-- id: cannot-publish -->

單單登入並不會取得發佈權限。請檢查你的方案是否生效，以及你是否符合發佈資格及商業條款。

Related: [服務條款](https://frely.cloud/terms/)

## 銷售收入是否等同利潤或可提取的餘額？
<!-- id: revenue -->

不是。創作者須自行承擔模型及服務的運行成本，而收入不會自動成為利潤或你可提取的餘額。結算按服務條款處理。

Related: [服務條款](https://frely.cloud/terms/)

## 我需要甚麼權利？
<!-- id: rights -->

你必須持有分發你所發佈的檔案及內容的權利，並在需要時註明原始來源。侵犯他人權利的內容一律不允許。

Related: [服務條款](https://frely.cloud/terms/)

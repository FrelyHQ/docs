# 帳戶與登入

## 如何取得 Frely 帳戶？
<!-- id: create-account -->

開啟 User Console（用戶主控台）並使用登入流程。新帳戶可透過網站提供的註冊入口或團隊邀請入口建立。雖然註冊目前只限獲邀人士，你可以在早期存取頁面申請早期存取，Frely 會以電郵發出邀請。

Related: [申請早期存取](https://frely.cloud/early-access/)

## 是否設有年齡限制？
<!-- id: age -->

有。本服務只供 18 歲或以上人士使用。你必須提供準確的帳戶資料，並保持對你的登入憑證、API Key、裝置及工作階段的控制權。

Related: [服務條款](https://frely.cloud/terms/)

## 我無法登入，應該怎樣做？
<!-- id: cannot-sign-in -->

請使用登入頁面上的意見回饋功能、密碼復原流程，或你的團隊邀請。Frely 網站絕不會要求你以電郵傳送密碼。如果上述方法都無效，請以電郵聯絡支援團隊，並提供你的帳戶電郵地址或用戶名稱，以及問題發生的時間（請註明你的時區）。

Related: [聯絡支援](https://frely.cloud/support/)

Console: [帳戶安全](https://frely.cloud/user/account/security)

## 我懷疑我的帳戶或某個 API Key 已遭盜用。
<!-- id: compromise -->

請立即在主控台撤銷該 API Key，並以電郵聯絡支援團隊。凡使用你的帳戶或 API 憑證進行的活動，均須由你負責，因此如懷疑帳戶被盜用，必須盡快通報。

Related: [聯絡支援](https://frely.cloud/support/) · [服務條款](https://frely.cloud/terms/)

Console: [你的 API Key](https://frely.cloud/user/account/keys)

API tools: `keys.list`, `keys.set_status`, `keys.revoke`

## 我可以關閉帳戶或刪除我的資料嗎？
<!-- id: close-account -->

請以電郵向支援團隊提出你的要求。Frely 可能會要求你提供資料，以核實你的身份。Frely 因付款、會計、保安、防止詐騙、爭議、法律或審計等原因而必須保留的紀錄，不會應要求刪除。

Related: [聯絡支援](https://frely.cloud/support/) · [私隱政策](https://frely.cloud/privacy/)

# 如何更新 Frely CLI？

執行 `frely update`。它會保留你的登入狀態、裝置、URL 及工作區，絕不降級，會暫停背景服務，經檢查後更換程式，然後重新啟動服務。在 Windows 上，它會輸出一條 PowerShell 命令，讓你在本機終端機執行。重新執行 https://frely.cloud/start.sh 亦會更新並重新啟動服務。

Related: [自我更新文件](https://github.com/FrelyHQ/frely-cli/blob/main/docs/self-update.md) · [start.sh](https://frely.cloud/start.sh)

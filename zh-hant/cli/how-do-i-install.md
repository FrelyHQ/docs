# How to install Frely CLI?

On macOS or Linux, run `curl -fsSL https://frely.cloud/start.sh | sh`. On Windows, run the PowerShell command shown on the install page. The script installs the latest version of `frely`, then runs `frely link on`, which opens the browser for you to sign in (new accounts can register on the same page), asks you to approve the device and prints out your MCP URL. Run the command again at any time to update.

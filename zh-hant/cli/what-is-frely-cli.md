# Frely CLI 是甚麼？

Frely CLI（即 `frely` 命令）可將你選定的電腦變成一台裝置，讓 AI Agent 能夠隨時隨地在上面工作。ChatGPT、Claude、Codex 及其他 MCP 客戶端會透過 FrelyMCP 連接，並使用你所允許的資料夾內的檔案、shell 指令及處理程序。這部電腦會主動向外連接至 Frely，因此你無需開啟任何連接埠。它同時也是你 Frely 帳戶的命令列工具。

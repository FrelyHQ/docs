# 如何新增另一部電腦？

在新電腦上執行安裝指令，或者要求已連接到 FrelyMCP 的 ChatGPT 或 Claude 為你新增電腦：`list_devices` 會傳回一條安裝指令。你也可以在 Frely App 的 My Devices（我的裝置）內建立。凡是你執行過 `frely link on` 的電腦，都會出現在同一個 MCP URL 後面，而且所有用戶端都會共用每部電腦的工作區和執行中的程序。

Related: [Frely App（我的裝置）](https://frely.cloud/app/) · [FrelyMCP 端點](https://mcp.frely.cloud/mcp)

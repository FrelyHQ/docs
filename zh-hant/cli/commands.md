# CLI 有哪些指令？

主要指令包括：`frely link on|status|stop|off|auto-update`、`frely link workspace list|add|remove`、`frely link local list|add|remove`、`frely doctor`、`frely update`、`frely login`、`frely logout`、`frely uninstall`、`frely agent install|run|result|runs|cancel|status|remove`、`frely item install|update|trust`、`frely provider share|list` 及 `frely api list|describe|call`。不加子指令執行任何指令群組（例如 `frely link`）即可查看其提供的內容；`frely help --agent --json` 則會輸出完整的機器可讀合約。

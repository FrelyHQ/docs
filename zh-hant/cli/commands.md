# CLI 有哪些指令？

主要指令包括：`frely link on|status|stop|off|auto-update`、`frely link workspace list|add|remove`、`frely link local list|add|remove`、`frely doctor`、`frely self update`、`frely login`、`frely logout`、`frely self uninstall`、`frely item install|update|trust|call|status|remove`、`frely result|result list|result cancel`、`frely service share|list|stop|remove`、`frely agent list|status|run|setup|start|stop|logs|remove|key`、`frely provider list` 及 `frely api list|describe|call`。不加子指令執行任何指令群組（例如 `frely link`）即可查看其提供的內容；`frely help --agent --json` 則會輸出完整的機器可讀合約。

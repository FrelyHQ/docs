# 如何將 ChatGPT 或 Claude 連接至我的電腦？

首先在電腦上執行 `frely link on`；它會輸出 MCP URL。FrelyMCP 是你整個帳戶通用的單一地址：https://mcp.frely.cloud/mcp。在 ChatGPT 或 Claude 中，使用該 URL 新增 custom connector（自訂連接器），登入 Frely 並批准該用戶端。如要驗證，可要求該用戶端列出工作區的頂層名稱。

Related: [FrelyMCP 端點](https://mcp.frely.cloud/mcp) · [安裝頁面](https://cli.frely.cloud/#install) · [README](https://github.com/FrelyHQ/frely-cli/blob/main/README.md)

# Qual é o meu URL de MCP e este muda?

O endereço do FrelyMCP é https://mcp.frely.cloud/mcp para todos os computadores da sua conta. Nunca muda e não contém nenhum segredo; os clientes detêm os tokens OAuth. Execute `frely link on` para imprimir o URL, ou `frely link status` (adicione `--json` para scripts) para mostrar o URL, a área de trabalho, a data de expiração da autorização e o estado do serviço.

Related: [Endpoint do FrelyMCP](https://mcp.frely.cloud/mcp) · [README](https://github.com/FrelyHQ/frely-cli/blob/main/README.md)

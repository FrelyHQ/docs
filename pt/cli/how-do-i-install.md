# Como instalar o Frely CLI?

No macOS ou Linux, execute `curl -fsSL https://frely.cloud/start.sh | sh`. No Windows, execute o comando PowerShell indicado na página de instalação. O script instala a versão mais recente do `frely` e, em seguida, executa `frely link on`, que abre o browser para iniciar sessão (as novas contas podem registar-se na mesma página), pede-lhe que aprove o dispositivo e apresenta o seu URL MCP. Execute-o novamente em qualquer altura para o atualizar.

Related: [Página de instalação](https://cli.frely.cloud/#install) · [start.sh](https://frely.cloud/start.sh) · [start.ps1 (Windows)](https://frely.cloud/start.ps1)

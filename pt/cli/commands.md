# Que comandos tem a CLI?

Os principais: `frely link on|status|stop|off|auto-update`, `frely link workspace list|add|remove`, `frely link local list|add|remove`, `frely doctor`, `frely self update`, `frely login`, `frely logout`, `frely self uninstall`, `frely item install|update|trust|call|status|remove`, `frely result|result list|result cancel`, `frely service share|list|stop|remove`, `frely agent list|status|run|setup|start|stop|logs|remove|key`, `frely provider list` e `frely api list|describe|call`. Execute qualquer grupo de comandos sem um subcomando (por exemplo, `frely link`) para ver o que este oferece; `frely help --agent --json` imprime o contrato completo legível por máquina.

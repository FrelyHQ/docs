# Que comandos tem a CLI?

Os principais: `frely link on|status|stop|off|auto-update`, `frely link workspace list|add|remove`, `frely link local list|add|remove`, `frely doctor`, `frely update`, `frely login`, `frely logout`, `frely uninstall`, `frely agent install|run|result|runs|cancel|status|remove`, `frely item install|update|trust`, `frely provider share|list` e `frely api list|describe|call`. Execute qualquer grupo de comandos sem um subcomando (por exemplo, `frely link`) para ver o que este oferece; `frely help --agent --json` imprime o contrato completo legível por máquina.

# Frely CLI는 어떻게 설치하나요?

macOS 또는 Linux에서는 `curl -fsSL https://frely.cloud/start.sh | sh`를 실행하세요. Windows에서는 설치 페이지에 표시된 PowerShell 명령을 실행하세요. 이 스크립트는 최신 버전의 `frely`를 설치한 다음 `frely link on`을 실행합니다. 이 명령은 브라우저를 열어 로그인을 진행하고(새 계정은 같은 페이지에서 가입할 수 있습니다), 기기 승인을 요청한 후 MCP URL을 출력합니다. 업데이트하려면 언제든지 다시 실행하면 됩니다.

Related: [설치 페이지](https://cli.frely.cloud/#install) · [start.sh](https://frely.cloud/start.sh) · [start.ps1 (Windows)](https://frely.cloud/start.ps1)

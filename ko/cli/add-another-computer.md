# 다른 컴퓨터는 어떻게 추가하나요?

새 컴퓨터에서 설치 명령어를 실행하거나, FrelyMCP에 연결된 ChatGPT나 Claude에게 컴퓨터 추가를 요청하세요: `list_devices`가 설치 명령어를 반환합니다. Frely App의 My Devices(내 기기)에서 직접 만들 수도 있습니다. `frely link on`을 실행한 모든 컴퓨터는 동일한 MCP URL 뒤에 나타나며, 모든 클라이언트가 각 컴퓨터의 워크스페이스와 실행 중인 프로세스를 공유합니다.

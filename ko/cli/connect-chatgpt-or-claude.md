# ChatGPT나 Claude를 내 컴퓨터에 어떻게 연결하나요?

먼저 컴퓨터에서 `frely link on`을 실행하면 MCP URL이 출력됩니다. FrelyMCP는 계정 전체에서 하나뿐인 주소입니다: https://mcp.frely.cloud/mcp. ChatGPT나 Claude에서 해당 URL로 custom connector(사용자 지정 커넥터)를 추가하고, Frely에 로그인한 뒤 클라이언트를 승인하세요. 확인하려면 클라이언트에게 워크스페이스의 최상위 이름 목록을 보여 달라고 요청하세요.

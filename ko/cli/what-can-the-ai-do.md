# 내 컴퓨터에서 AI가 무엇을 할 수 있나요?

FrelyMCP를 통해 AI는 `list_devices`(사용자의 컴퓨터 목록과 각 컴퓨터의 온라인 여부), `read`(워크스페이스에서 파일 나열, 읽기, 검색 및 찾기), `edit_file`(파일 전체 쓰기 또는 한 단계에서 줄 편집), `process`(셸 명령 실행 또는 장기 실행 프로세스 관리), `web_fetch`(공개 웹 페이지 읽기) 도구를 사용할 수 있습니다. 디바이스 도구는 `device` 인자를 받으며 해당 컴퓨터에서 실행됩니다. AI 클라이언트의 자체 셸은 여전히 클라이언트가 실행되는 위치에서 실행되므로, 사용자의 컴퓨터에서 작업할 때는 Frely 도구를 사용하도록 요청하세요.

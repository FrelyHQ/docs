# Frely CLI는 어떻게 업데이트하나요?

`frely update`를 실행하세요. 이 명령은 로그인, 기기, URL, 워크스페이스를 그대로 유지하고, 절대 다운그레이드하지 않으며, 백그라운드 서비스를 일시 중지한 후 프로그램을 검증하고 교체한 뒤 서비스를 다시 시작합니다. Windows에서는 로컬 터미널에서 실행할 PowerShell 명령을 출력합니다. https://frely.cloud/start.sh를 다시 실행해도 서비스가 업데이트되고 다시 시작됩니다.

Related: [자체 업데이트 문서](https://github.com/FrelyHQ/frely-cli/blob/main/docs/self-update.md) · [start.sh](https://frely.cloud/start.sh)

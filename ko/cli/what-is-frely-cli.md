# Frely CLI란 무엇인가요?

Frely CLI(`frely` 명령어)는 사용자가 선택한 컴퓨터를 AI 에이전트가 어디서든 작업할 수 있는 기기로 바꿔줍니다. ChatGPT, Claude, Codex 등 다른 MCP 클라이언트는 FrelyMCP를 통해 연결하여 사용자가 허용한 폴더의 파일, 셸 명령어, 프로세스를 사용합니다. 컴퓨터가 Frely로 바깥쪽으로 연결되기 때문에 포트를 열 필요가 없습니다. 또한 Frely 계정을 위한 명령줄 도구이기도 합니다.

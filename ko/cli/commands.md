# CLI에는 어떤 명령어가 있나요?

주요 명령어는 `frely link on|status|stop|off|auto-update`, `frely link workspace list|add|remove`, `frely link local list|add|remove`, `frely doctor`, `frely update`, `frely login`, `frely logout`, `frely uninstall`, `frely agent install|run|result|runs|cancel|status|remove`, `frely item install|update|trust`, `frely provider share|list` 및 `frely api list|describe|call`입니다. 명령 그룹을 하위 명령 없이 실행하면(예: `frely link`) 해당 그룹이 제공하는 명령을 확인할 수 있으며, `frely help --agent --json`을 실행하면 기계가 읽을 수 있는 전체 컨트랙트가 출력됩니다.

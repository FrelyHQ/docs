# 무언가 작동하지 않나요? 어떻게 진단하나요?

`frely doctor`를 실행하면 로그인 상태, 설치 상태, 최신 버전 여부, MCP 및 서비스 상태를 확인할 수 있습니다. `-v` 옵션을 추가하면 설정 파일 경로, 인증 만료 시간, 마지막 하트비트, 민감 정보가 제거된 오류 내용도 확인할 수 있습니다. 기기가 오프라인으로 표시되면 `frely link on`을 실행하세요. 이 명령은 다시 실행해도 안전합니다. 문제가 계속되면 Discord에서 문의하거나 `frely doctor -v` 출력 결과와 함께 GitHub 이슈를 열어 주세요.

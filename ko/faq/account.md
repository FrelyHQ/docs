# 계정 및 로그인

## Frely 계정은 어떻게 만들 수 있나요?
<!-- id: create-account -->

User Console(사용자 콘솔)을 열고 로그인 절차를 진행하세요. 새 계정은 사이트에서 제공하는 가입 또는 Team 초대 창구를 통해 만듭니다. 가입은 현재 초대제로 운영되므로, 얼리 액세스 페이지에서 얼리 액세스를 신청하면 Frely가 초대장을 이메일로 보내 드립니다.

Related: [얼리 액세스 신청](https://frely.cloud/early-access/)

## 연령 제한이 있나요?
<!-- id: age -->

네. 본 서비스는 만 18세 이상 사용자를 위한 것입니다. 정확한 계정 정보를 제공하고, 자격 증명, API Key, 기기 및 세션을 본인이 직접 관리해야 합니다.

Related: [서비스 약관](https://frely.cloud/terms/)

## 로그인할 수 없습니다. 어떻게 해야 하나요?
<!-- id: cannot-sign-in -->

로그인 페이지의 피드백 창구, 비밀번호 복구 절차 또는 Team 초대를 이용해 주세요. Frely 웹사이트가 이메일로 비밀번호를 보내 달라고 요청하는 일은 결코 없습니다. 어떤 방법으로도 해결되지 않으면, 계정 이메일 또는 사용자 이름과 문제가 발생한 시점(사용 중인 시간대 포함)을 고객 지원에 이메일로 알려 주세요.

Related: [고객 지원에 문의](https://frely.cloud/support/)

Console: [계정 보안](https://frely.cloud/user/account/security)

## 계정 또는 API Key가 유출된 것 같습니다.
<!-- id: compromise -->

콘솔에서 해당 API Key를 즉시 취소하고 고객 지원에 이메일로 알려 주세요. 계정 또는 API 자격 증명으로 수행된 활동에 대한 책임은 사용자에게 있으므로, 침해가 의심되는 경우 반드시 신고해야 합니다.

Related: [고객 지원에 문의](https://frely.cloud/support/) · [서비스 약관](https://frely.cloud/terms/)

Console: [내 API Key](https://frely.cloud/user/account/keys)

API tools: `keys.list`, `keys.set_status`, `keys.revoke`

## 계정을 삭제하거나 데이터를 지울 수 있나요?
<!-- id: close-account -->

요청 내용을 고객 지원에 이메일로 보내 주세요. Frely는 본인 확인을 위해 정보를 요청할 수 있습니다. 결제, 회계, 보안, 사기 방지, 분쟁, 법적 사유 또는 감사 목적으로 Frely가 보관해야 하는 기록은 삭제 요청이 있어도 삭제되지 않습니다.

Related: [고객 지원에 문의](https://frely.cloud/support/) · [개인정보 처리방침](https://frely.cloud/privacy/)

Skill을 만들어 GitHub에 올렸고, 사람들이 사용하고 있습니다. 그중 일부는 나머지보다 훨씬 많은 공을 들여 만든 부분입니다: 스크립트, 템플릿, 심층 참조 파일이 그렇습니다. Skill을 숨기고 싶지도, 모든 것을 넘겨주고 싶지도 않으시겠죠.

Frely는 그 중간 길을 제공합니다. **오픈 소스 부분은 무료로 공개된 채 유지되고, 고급 부분은 유료 패스 뒤에 위치합니다.** 저장소는 바뀌지 않습니다.

## 작동 방식

Skill을 Frely에 게시하고 유료 파일을 표시합니다:

- **`SKILL.md`는 항상 무료**이므로 구매자가 자신이 무엇을 받는지 확인할 수 있습니다.
- **유료 파일**은 개별 파일 또는 폴더 전체입니다(예: `scripts/` 또는 `reference/advanced.md`).
- **패스 기간마다 가격을 직접 정합니다**: 1시간, 8시간, 24시간, 7일, 30일, forever 중에서 선택하세요. 하나만 제공해도 되고 여섯 가지를 모두 제공해도 됩니다.

구매자는 명령 한 줄로 설치합니다: `frely item install <item-id>`. ChatGPT, Codex, Claude Code 등 Skill을 사용하는 다른 도구에서도 작동합니다. 패스가 활성화되어 있는 동안에는 Skill을 가져올 때 유료 파일도 함께 가져옵니다. 패스가 만료되면 설치가 유료 부분을 더 가져오지 않습니다. `forever` 패스는 구매자가 로컬 사본을 영구히 보유할 수 있게 하며 이후 업데이트도 포함됩니다.

## 메시지 한 번으로 게시하기

문서를 읽을 필요가 없습니다. 이미 사용 중인 AI에 다음을 보내세요(데스크톱 앱, Codex 또는 Claude Code처럼 컴퓨터에서 명령을 실행할 수 있는 AI여야 합니다):

`Follow https://frely.cloud/prompt/creator.md and publish this Skill: <your repository URL>`

AI는 Frely CLI를 설치하고 저장소를 읽은 뒤 정확히 세 가지를 묻습니다:

1. 어떤 파일을 유료로 할까요? 기본값으로 스크립트, 템플릿, 심층 참조 파일을 제안합니다.
2. 패스 기간별 가격은 얼마인가요?
3. `forever` 패스를 제공하시겠어요?

나머지는 AI가 알아서 처리하고, 아이템 id와 설치 명령어를 알려줍니다.

## 게시하기 전에 알아둘 사항

- **유료 부분은 구매한 사람에게 보입니다.** Skill은 구매자 본인의 기기에 설치되므로, 무료 부분은 모두에게 보이고 유료 부분은 패스를 가진 모든 사람에게 보입니다. 콘텐츠를 비공개로 유지해야 한다면, 대신 호스팅 Agent로 게시하세요. 이 경우 사용자는 결과를 받지만 프롬프트는 절대 볼 수 없습니다.
- **라이선스를 확인하세요.** 저장소의 라이선스가 재배포를 금지하는 경우 게시하지 마세요. 소스 URL이 출처 표시로 보여지며, Frely는 저장소 소유권을 확인하지 않습니다.
- **크기 제한.** 압축된 Skill은 최대 256 KiB, 64개 파일, 파일당 64 KiB, 총 128 KiB입니다.
- **받는 것은 현금이 아니라 Frely Credit입니다.** 사용료는 30일 동안 보관된 후 Frely Credit에 추가되며, 이 Credit은 Frely에서 사용할 수 있습니다. 출금하거나 이전할 수는 없습니다. Frely는 판매 건마다 플랫폼 수수료를 받으며, 그 수수료는 가격을 설정할 때 페이지에 표시됩니다.
- **무료 계정으로는 아이템을 하나만 게시할 수 있습니다.**

## 업데이트하거나 내리기

새 버전을 출시하려면 같은 slug로 다시 게시하세요. 내리려면 게시 취소 상태로 표시하세요. GitHub 저장소는 전혀 건드리지 않으므로 오픈 소스 버전은 늘 그 자리에 그대로 남아 있습니다.

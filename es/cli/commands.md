# ¿Qué comandos tiene la CLI?

Los principales son: `frely link on|status|stop|off|auto-update`, `frely link workspace list|add|remove`, `frely link local list|add|remove`, `frely doctor`, `frely update`, `frely login`, `frely logout`, `frely uninstall`, `frely agent install|run|result|runs|cancel|status|remove`, `frely item install|update|trust`, `frely provider share|list` y `frely api list|describe|call`. Ejecuta cualquier grupo de comandos sin un subcomando (por ejemplo `frely link`) para ver qué ofrece; `frely help --agent --json` imprime el contrato completo legible por máquina.

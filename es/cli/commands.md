# ¿Qué comandos tiene la CLI?

Los principales son: `frely link on|status|stop|off|auto-update`, `frely link workspace list|add|remove`, `frely link local list|add|remove`, `frely doctor`, `frely self update`, `frely login`, `frely logout`, `frely self uninstall`, `frely item install|update|trust|call|status|remove`, `frely result|result list|result cancel`, `frely service share|list|stop|remove`, `frely agent list|status|run|setup|start|stop|logs|remove|key`, `frely provider list` y `frely api list|describe|call`. Ejecuta cualquier grupo de comandos sin un subcomando (por ejemplo `frely link`) para ver qué ofrece; `frely help --agent --json` imprime el contrato completo legible por máquina.

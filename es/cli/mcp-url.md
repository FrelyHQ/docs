# ¿Cuál es mi URL de MCP y cambia?

La dirección de FrelyMCP es https://mcp.frely.cloud/mcp para cada computadora de tu cuenta. Nunca cambia y no contiene ningún secreto; los clientes guardan los tokens de OAuth. Ejecuta `frely link on` para imprimir la URL, o `frely link status` (agrega `--json` para scripts) para mostrar la URL, el espacio de trabajo, el vencimiento de la autorización y el estado del servicio.

# ¿Cómo instalo Frely CLI?

En macOS o Linux ejecuta `curl -fsSL https://frely.cloud/start.sh | sh`. En Windows ejecuta el comando de PowerShell que aparece en la página de instalación. El script instala la versión más reciente de `frely`, luego ejecuta `frely link on`, que abre el navegador para iniciar sesión (las cuentas nuevas pueden registrarse en la misma página), te pide aprobar el dispositivo y muestra tu URL de MCP. Ejecútalo de nuevo en cualquier momento para actualizar.

Related: [Página de instalación](https://cli.frely.cloud/#install) · [start.sh](https://frely.cloud/start.sh) · [start.ps1 (Windows)](https://frely.cloud/start.ps1)

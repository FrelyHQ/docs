# ¿Cómo actualizo Frely CLI?

Ejecuta `frely update`. Conserva tu inicio de sesión, dispositivo, URL y espacio de trabajo, nunca instala una versión anterior, pausa el servicio en segundo plano, reemplaza el programa después de verificarlo y reinicia el servicio. En Windows muestra un comando de PowerShell para ejecutar en una terminal local. Volver a ejecutar https://frely.cloud/start.sh también actualiza y reinicia el servicio.

Related: [Doc de autoactualización](https://github.com/FrelyHQ/frely-cli/blob/main/docs/self-update.md) · [start.sh](https://frely.cloud/start.sh)

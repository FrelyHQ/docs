# Устройства и Frely CLI

## Как установить Frely CLI и привязать компьютер?
<!-- id: install -->

Запустите скрипт установки: curl -fsSL https://frely.cloud/install.sh | sh. Он устанавливает frely и запускает frely mcp start, который открывает браузер для входа в аккаунт (новый аккаунт можно зарегистрировать на той же странице), просит подтвердить устройство и выводит ваш MCP URL. Запустите его снова в любой момент, чтобы обновить.

Related: [руководство по FrelyMCP](https://frely.cloud/docs/frelymcp/)

## В моём AI-приложении не отображается устройство.
<!-- id: no-device -->

Запустите frely mcp start на компьютере и убедитесь, что CLI вошёл в тот же аккаунт Frely, что и ваше AI-приложение.

Related: [руководство по FrelyMCP](https://frely.cloud/docs/frelymcp/)

## Устройство отображается как офлайн.
<!-- id: offline -->

Включите компьютер, подключите его к интернету и снова запустите frely mcp start. Команда frely doctor показывает аккаунт, установку, версию, состояние MCP и службы; добавьте -v для подробностей.

Console: [Мои устройства](https://frely.cloud/user/device)

## Срок действия доступа устройства истёк.
<!-- id: expired -->

Доступ устройства через MCP по умолчанию действует 90 дней. Запустите frely mcp start, чтобы подтвердить устройство заново (frely mcp start --days с числом от 1 до 365 позволяет продлить доступ заранее). MCP URL не меняется. Управлять компьютерами можно в разделе «Мои устройства» на сайте Frely.

Console: [Мои устройства](https://frely.cloud/user/device)

## Почему AI-приложение запрашивает разрешение на чтение некоторых папок?
<!-- id: permissions -->

Команды выполняются в песочнице, которая блокирует папки с учётными данными, такие как ~/.ssh и ~/.aws, а инструменты работают только с теми рабочими областями, которые вы зарегистрировали. Когда задаче требуется больше, приложение обязано спросить: вы решаете на сайте Frely, разрешить ли доступ и на какой срок, и позже можете его отозвать. AI-приложение не может одобрить собственный запрос.

Related: [руководство по FrelyMCP](https://frely.cloud/docs/frelymcp/) · [How the sandbox protects your data](https://frely.cloud/connect/sandbox/)

## Как удалить Frely с компьютера?
<!-- id: uninstall -->

Запустите frely uninstall в локальном терминале. Сначала команда показывает список всего, что будет удалено, и удаляет его после того, как вы введёте yes. Она отзывает доступ этого компьютера, удаляет службу, сохранённые данные для входа, идентификатор устройства, настройки и кэши, а в конце — саму программу frely. Ваши Providers и Agents останутся в аккаунте.

# FrelyMCP

FrelyMCP — это MCP-сервер для вашего аккаунта Frely. Подключите его один раз, и ваше AI-приложение сможет обращаться к вашим компьютерам, включённым облачным инструментам, а также к вашим моделям и AI-агентам. Вход выполняется через OAuth; вставлять API Key в приложение не нужно.

## Что оно делает
<!-- id: what -->

Локально: смотреть список компьютеров, привязанных к вашему аккаунту, читать файлы в рабочей области, редактировать файлы, запускать команды и загружать веб-страницы на них. Чтение и запись локальных файлов — лишь часть возможностей. Облако: использовать облачные MCP-серверы, включённые для этого подключения, — устройство не нужно. Модели и агенты: смотреть список доступных моделей и агентов, включать или выключать их для MCP и обращаться к ним прямо из вашего AI-приложения. Можно подключить и собственного агента — он работает как модель. Использование тарифицируется на ваш аккаунт Frely.

## Перед началом
<!-- id: before -->

Вам нужен аккаунт Frely (вход на frely.cloud). Чтобы использовать инструменты устройства, установите Frely CLI на компьютер и привяжите его. Модели, агенты и облачные инструменты работают без устройства.

```sh
curl -fsSL https://frely.cloud/install.sh | sh
frely login
frely mcp start
```

## Подключите своё AI-приложение
<!-- id: connect -->

Используйте этот адрес как URL MCP-сервера и выберите OAuth. Не добавляйте заголовки аутентификации.

```sh
https://mcp.frely.cloud/mcp
```

## Claude
<!-- id: claude -->

В Claude откройте Settings (Настройки), перейдите в раздел Connectors (Коннекторы), выберите Add custom connector (Добавить собственный коннектор), введите FrelyMCP в качестве имени и вставьте адрес выше. Нажмите Connect (Подключить), войдите в Frely и разрешите доступ. Для Claude Code выполните: claude mcp add --transport http frelymcp https://mcp.frely.cloud/mcp, затем /mcp для входа.

## ChatGPT
<!-- id: chatgpt -->

В ChatGPT откройте Settings (Настройки) и перейдите в раздел для приложений и коннекторов. Создайте новый коннектор, вставьте адрес выше, выберите OAuth и войдите в Frely. Пользовательские коннекторы могут требовать режим разработчика — в зависимости от вашего тарифа ChatGPT.

## Установка через файл конфигурации
<!-- id: config -->

Некоторые AI-агенты, например WorkBuddy, добавляют MCP-серверы через файл конфигурации, а не через экран коннекторов. Добавьте эту запись в объект mcpServers в файле конфигурации MCP агента (сохраните серверы, которые там уже есть). Затем перезапустите агента и завершите вход в Frely и подтверждение доступа, когда он попросит. Если ваш агент не принимает поле url, используйте его опцию удалённого или HTTP-сервера с тем же адресом.

```json
{
  "mcpServers": {
    "frely": {
      "url": "https://mcp.frely.cloud/mcp"
    }
  }
}
```

## Инструменты
<!-- id: tools -->

Инструменты, которые может вызывать ваше AI-приложение:

| Инструмент | Что делает |
| --- | --- |
| `list_devices` | Показывает ваши привязанные компьютеры, их рабочие области и то, находятся ли они в сети. Вызывайте его первым. |
| `read` | Читает файлы и папки внутри рабочей области. |
| `edit_file` | Создаёт или изменяет файл внутри рабочей области. |
| `process` | Выполняет команду на устройстве и возвращает её вывод. |
| `web_fetch` | Загружает веб-страницу с устройства. |
| `request_permission / confirm_permission` | Запрашивает у вас подтверждение доступа за пределами стандартной песочницы, например к ~/.ssh. Подтверждение выполняется на сайте Frely с помощью кода. |
| `models_list / models_set / models_invoke` | Показывает список ваших моделей и агентов, включает или выключает одну из них для MCP и обращается к ней. Каждая включённая также доступна как <model>__invoke. |
| `<mcp>__<tool>` | Инструменты облачных MCP-серверов, включённых для этого подключения. Они выполняются в облаке и не требуют устройства. |
| `local_mcp_list / local_mcp_call` | Обращается к MCP-серверам, работающим на устройстве, если устройство их предоставляет. |
| `frely_list / frely_call` | Управляет вашим аккаунтом Frely: API-ключами, кредитами, тарифами, заказами и материалами Creator. Выполняются в облаке и не требуют устройства. Новое подключение может только читать, пока вы не разрешите больше на сайте Frely; действия, которые переводят деньги или меняют учётные данные, требуют вашего подтверждения каждый раз, а оплаты открывают страницу оплаты. |
| `store` | Показывает Frely Store (подписки, тарифы, Credit, расширения, Skills, сервисы) в виде карточки или таблицей в приложениях без карточек. Каждая ссылка Buy открывает этот продукт на сайте Frely, где вы и оплачиваете. |

## Безопасность и подтверждение доступа
<!-- id: safety -->

Команды выполняются в песочнице на вашем компьютере, которая блокирует папки с учётными данными, такие как ~/.ssh и ~/.aws, а инструменты работают только с зарегистрированными вами рабочими областями. Когда задаче требуется больше, AI-приложение должно запросить это через request_permission. Решение вы принимаете на сайте Frely, выбираете срок действия и можете позже отозвать доступ. AI-приложение не может одобрить собственный запрос.

## Ваши данные
<!-- id: data -->

Вызовы инструментов устройства (read, edit_file, process, web_fetch и локальный MCP) передаются на ваш собственный компьютер; FrelyMCP хранит о них только записи о входе через OAuth. Вызовы моделей и агентов идут через шлюз Frely. Request Capture может хранить содержимое их запросов и ответов ограниченное время, а выбранный вами поставщик модели получает данные запроса, необходимые для ответа. Подробности — в Политике конфиденциальности, разделы 4 и 6. Frely Credit не подлежит передаче; вызовы моделей списываются только с вашего собственного Credit.

## Если что-то не работает
<!-- id: help -->

Если list_devices не показывает ни одного устройства, выполните frely mcp start на компьютере и убедитесь, что в CLI выполнен вход в тот же аккаунт Frely. Если устройство не в сети, включите компьютер и выполните ту же команду. Другие вопросы: support@frely.cloud.

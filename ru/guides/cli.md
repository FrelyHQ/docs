# Использование Frely со Skill и CLI

Frely CLI — это интерфейс командной строки для вашей учётной записи Frely. Его Skill обучает ИИ-агента, у которого есть оболочка (Claude Code, Codex, pi и подобные), пользоваться этой командной строкой: входить в систему, обращаться к вашей учётной записи Frely, устанавливать то, что вы приобрели, и выполнять команды на ваших собственных компьютерах. Это рекомендуемый способ работы с Frely из ИИ-агента. Если ваше ИИ-приложение не может выполнять команды, используйте вместо этого руководство по FrelyMCP (альтернативный вариант).

## Перед началом работы
<!-- id: before -->

Вам понадобятся учётная запись Frely (войдите на frely.cloud) и ИИ-агент, который может выполнять команды оболочки на компьютере, где вы устанавливаете CLI. CLI работает на macOS, Linux и Windows.

## Установка CLI
<!-- id: install -->

Выполните команду для своей системы. Она устанавливает только программу `frely`.

```sh
curl -fsSL https://frely.cloud/install.sh | sh
```

В Windows выполните эту команду в PowerShell:

```sh
curl.exe -fsSLo "$env:TEMP\frely-install.ps1" https://frely.cloud/install.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\frely-install.ps1"
```

## Вход в систему
<!-- id: login -->

Выполните приведённую ниже команду. Она откроет браузер, чтобы вы могли войти в систему или зарегистрироваться и подтвердить этот компьютер. На компьютере без браузера выполните `frely login --email` и введите код, отправленный на вашу почту.

```sh
frely login
```

## Установка Skill
<!-- id: skill -->

Установите Skill `frely` в вашего ИИ-агента. Замените `<host>` на `claude-code`, `codex`, `pi`, `chatgpt` или `generic`. Затем перезапустите сессию агента, чтобы он нашёл Skill.

```sh
frely skill install --host <host>
```

## Обратитесь к агенту
<!-- id: use -->

Скажите агенту обычными словами, что вам нужно, например: «Покажи мои компьютеры Frely», «Запусти тесты на моём офисном компьютере» или «Установи Skill, который я купил на Frely». Агент выполняет команды `frely` за вас. Когда агент впервые получает управление компьютером, Frely просит вас подтвердить это на сайте Frely с помощью короткого кода. Агент не может подтвердить свой собственный запрос.

## Сделайте компьютер управляемым
<!-- id: device -->

Чтобы ваш агент мог работать на другом компьютере, выполните эту команду на нём. Она выполняет вход, подтверждает компьютер и запускает фоновую службу. Для сервера без браузера создайте одноразовую команду установки в приложении Frely в разделе My Devices (Мои устройства).

```sh
frely link on
```

## Команды, которые использует ваш агент
<!-- id: commands -->

| Команда | Что она делает |
| --- | --- |
| `frely devices` | Показывает ваши компьютеры и то, находятся ли они в сети. |
| `frely run <device> -- <command>` | Выполняет команду на компьютере. |
| `frely read <device>:<path>` | Читает файл или папку на компьютере. |
| `frely edit <device>:<path> --from <file>` | Записывает файл на компьютер. |
| `frely item install <username/name> --host <host>` | Устанавливает Skill, Prompt или Agent из Frely. |
| `frely api list` | Показывает инструменты учётной записи, которые может вызывать ваш агент. |
| `frely doctor` | Проверяет вход в систему, установку и подключение. |

## Если что-то не работает
<!-- id: help -->

Если агент не использует Frely, перезапустите сессию агента и проверьте, что команда `frely skill install` завершилась. Если команда `frely` не найдена, откройте новый терминал и выполните её снова. Если компьютер отображается как офлайн, выполните на нём `frely link on`. Если команда запрашивает подтверждение, откройте выведенную ею ссылку и подтвердите действие на сайте Frely. Другие вопросы: support@frely.cloud.

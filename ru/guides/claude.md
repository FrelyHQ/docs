# Использование Frely в Claude

Подключитесь один раз. Claude выполняет вход в Frely и после этого сможет показывать список ваших моделей и вызывать опубликованные модели.

## Перед началом работы
<!-- id: before -->

- Аккаунт Frely. Войдите на frely.cloud.
- Включённый API key в вашем рабочем пространстве Frely. Вызовы моделей тарифицируются на ваш аккаунт через него.

## Приложение Claude (веб и десктоп)
<!-- id: connector -->
<!-- badge: recommended -->

1. В Claude откройте Settings (Настройки), перейдите в раздел Connectors (Коннекторы) и выберите Add custom connector (Добавить пользовательский коннектор).
2. Введите Frely в качестве имени и вставьте этот адрес в поле URL:

   ```sh
   https://frely.cloud/mcp
   ```
   <!-- mock: connector -->
3. Не добавляйте заголовки аутентификации. Claude использует OAuth.
4. Выберите Connect, войдите в Frely и подтвердите доступ.
   <!-- mock: consent -->
5. В чате откройте меню инструментов, включите Frely и попросите Claude использовать вашу модель. Например: «Используй мою модель Frely GPT-800, чтобы проверить этот текст».
   <!-- mock: chat -->

## Claude Code
<!-- id: claude-code -->

1. Добавьте Frely как сервер MCP:

   ```sh
   claude mcp add --transport http frely https://frely.cloud/mcp
   ```
2. Выполните /mcp в Claude Code, выберите frely и войдите в Frely в своём браузере.

   ```sh
   /mcp
   ```
3. Чтобы вместо этого добавить одну модель как Skill, установите Frely CLI, выполните frely login и установите модель:

   ```sh
   frely agent install <model-link> --host claude-code
   ```

## Если что-то не работает
<!-- id: troubleshooting -->

| Проблема | Что делать |
| --- | --- |
| Claude не показывает инструменты Frely | Включите Frely в меню инструментов чата или начните новый чат после подключения. |
| Не удаётся войти или доступ запрещён | Войдите с тем же аккаунтом Frely, которому принадлежит API key. Удалите коннектор и добавьте его снова, чтобы повторить вход. |
| При вызове сообщается, что требуется API key | Создайте или включите API key в своём рабочем пространстве Frely, затем повторите попытку. |

# Использование Frely в ChatGPT

Подключитесь один раз. ChatGPT выполняет вход в Frely и после этого может выводить список ваших моделей и вызывать опубликованные модели.

## Перед началом
<!-- id: before -->

- Аккаунт Frely. Войдите на frely.cloud.
- Включённый API key в вашем рабочем пространстве Frely. Вызовы моделей тарифицируются на ваш аккаунт через него.

## Добавьте Frely как коннектор
<!-- id: connector -->
<!-- badge: recommended -->

1. В ChatGPT откройте Settings (Настройки) и перейдите в раздел приложений и коннекторов. Создайте новый коннектор. Пользовательские коннекторы могут требовать включения режима разработчика — это зависит от вашего тарифа ChatGPT.
2. Введите Frely в качестве имени и вставьте этот адрес как URL MCP-сервера:

   ```sh
   https://frely.cloud/mcp
   ```
   <!-- mock: connector -->
3. Выберите OAuth для аутентификации. Не добавляйте API key или заголовок авторизации.
4. Выполните вход в Frely в открывшемся окне и подтвердите доступ.
   <!-- mock: consent -->
5. В новом чате включите коннектор Frely и попросите ChatGPT использовать вашу модель. Например: «Используй мою модель Frely GPT-800, чтобы проверить этот текст.»
   <!-- mock: chat -->

## Вставьте промпт установки
<!-- id: prompt -->

Этот способ устанавливает Frely CLI, поэтому ChatGPT нужно разрешение на выполнение команд на вашем компьютере.

1. В рабочем пространстве Frely откройте модель и выберите Copy for ChatGPT (Скопировать для ChatGPT). Если моделью с вами поделился кто-то другой, используйте присланную вам ссылку для установки.
2. Вставьте её в ChatGPT. ChatGPT установит Frely CLI, выполнит вход в Frely в вашем браузере и добавит модель как Skill.
3. Если ChatGPT попросит перезагрузить Skill, перезагрузите его. Затем вызывайте модель по имени.

## Используйте командную строку
<!-- id: cli -->

1. Установите Frely CLI:

   ```sh
   curl -fsSL https://frely.cloud/install.sh | sh
   ```
2. Выполните вход в Frely:

   ```sh
   frely login
   ```
3. Установите модель как Skill для ChatGPT. Используйте ссылку на модель из инструкций по её установке:

   ```sh
   frely agent install <model-link> --host chatgpt
   ```

## Если что-то не работает
<!-- id: troubleshooting -->

| Проблема | Что делать |
| --- | --- |
| ChatGPT не показывает инструменты Frely | Включите коннектор Frely в чате или начните новый чат после его добавления. |
| Вход не выполняется или доступ запрещён | Войдите с тем же аккаунтом Frely, которому принадлежит API key. Удалите коннектор и добавьте его заново, чтобы перезапустить вход. |
| При вызове появляется сообщение, что требуется API key | Создайте или включите API key в рабочем пространстве Frely, затем попробуйте снова. |

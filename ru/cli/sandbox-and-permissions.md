# Команда не выполнилась из-за песочницы. Что можно сделать?

На странице подключений Frely можно открыть для подключения больше возможностей: папки с учётными данными для чтения, дополнительные папки для записи или запуск без песочницы на ограниченное время. На Windows, а также на Linux без bubblewrap, socat и ripgrep команды отклоняются, потому что компьютер не может создать песочницу; установите эти инструменты на Linux. `FRELY_SANDBOX=off` отключает песочницу только на самом устройстве; используйте его, только если принимаете риск.

# Что происходит, когда Frely Agent работает долго?

Команда `frely agent run` записывает запуск на вашем компьютере, а фоновый процесс дожидается Agent, поэтому долгая задача продолжит выполняться, даже если команда оборвётся. Задача продолжает работать на Frely; чтение её состояния ничего не стоит. Если команда завершилась раньше, чем пришёл ответ, выполните `frely agent result --last --wait` (или `frely agent result <runId> --wait`). Пока запуск идёт, команда `frely agent result <runId>` показывает его последнюю строку прогресса, если Agent её записал. Остановить запуск можно командой `frely agent cancel <runId>`; задача остановится и на стороне Frely, а за уже выполненную часть спишется оплата. Цена, которую установил Creator агента, списывается, когда задача завершается, когда вы её отменяете или когда Agent уже вернул результат; за задачу, завершившуюся ошибкой без результата, оплата не взимается. Чтобы скрыть строки прогресса, добавьте `--no-progress-summary` к `frely agent run` или напишите `When calling Frely Agents, pass --no-progress-summary.` в файле `AGENTS.md` или `CLAUDE.md`, который читает ваш ИИ.

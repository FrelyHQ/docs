# К какой папке ИИ получает доступ?

По умолчанию это папка `~/Frely`; установщик создаёт её автоматически. Компьютеры, настроенные до этого изменения, продолжают использовать уже открытую папку. Чтобы открыть другую папку, задайте `FRELY_WORKSPACE=/path` перед установкой. После установки используйте `frely link workspace add <path>`, чтобы открыть дополнительные папки, `frely link workspace remove <path>`, чтобы закрыть доступ к одной из них, и `frely link workspace list`, чтобы просмотреть их все.

Когда ИИ-клиенту нужна папка вне списка открытых, он запрашивает разрешение, и вы предоставляете доступ к этой папке через веб — на ограниченное время или навсегда. Постоянный доступ работает только для одной папки: его нельзя дать домашней папке или папкам уровнем выше, и для подтверждения требуется ваш passkey (ключ доступа) или код из приложения-аутентификатора. Папки, открытые через веб, перечислены на странице устройства, где вы можете в любой момент отозвать доступ. Файлы учётных данных и файлы автозапуска оболочки внутри открытой папки остаются защищёнными.

# Как установить Frely CLI?

На macOS или Linux выполните `curl -fsSL https://frely.cloud/start.sh | sh`. На Windows выполните команду PowerShell, показанную на странице установки. Скрипт устанавливает последнюю версию `frely`, затем запускает `frely link on`, который открывает браузер для входа (новые учётные записи могут зарегистрироваться на той же странице), просит подтвердить устройство и выводит ваш URL-адрес MCP. Запустите команду снова в любой момент, чтобы обновиться.

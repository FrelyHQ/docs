# Безопасно ли разрешать ИИ пользоваться моим компьютером?

Доступ ограничен теми папками, которыми вы делитесь. Инструменты работы с файлами отклоняют попытки выйти через символические ссылки за разрешённые папки и ограничивают чтение и запись объёмом 1 МиБ. Команды выполняются от имени вашего пользователя ОС внутри песочницы операционной системы: папки с учётными данными недоступны для чтения, запись разрешена только в рабочую папку и временный каталог, а сетевой трафик идёт через прокси. Если на компьютере невозможно создать песочницу, команды отклоняются, а не выполняются без защиты. URL MCP не содержит никаких секретов, а CLI хранит свой ключ выполнения в зашифрованном виде в хранилище учётных данных ОС. Отозвать доступ можно в любой момент с помощью `frely link off`; эта команда отменяет доступ для всех клиентов и блокирует удалённое управление на этом компьютере, пока вы не выполните на нём `frely link on`.

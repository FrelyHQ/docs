# Какие команды есть у CLI?

Основные: `frely link on|status|stop|off|auto-update`, `frely link workspace list|add|remove`, `frely link local list|add|remove`, `frely doctor`, `frely self update`, `frely login`, `frely logout`, `frely self uninstall`, `frely item install|update|trust|call|status|remove`, `frely result|result list|result cancel`, `frely service share|list|stop|remove`, `frely agent list|status|run|setup|start|stop|logs|remove|key`, `frely provider list` и `frely api list|describe|call`. Запустите любую группу команд без подкоманды (например, `frely link`), чтобы увидеть, что она предлагает; `frely help --agent --json` выводит полный машиночитаемый контракт.

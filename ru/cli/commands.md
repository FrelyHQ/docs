# Какие команды есть у CLI?

Основные: `frely link on|status|stop|off|auto-update`, `frely link workspace list|add|remove`, `frely link local list|add|remove`, `frely doctor`, `frely update`, `frely login`, `frely logout`, `frely uninstall`, `frely agent install|run|result|runs|cancel|status|remove`, `frely item install|update|trust`, `frely provider share|list` и `frely api list|describe|call`. Запустите любую группу команд без подкоманды (например, `frely link`), чтобы увидеть, что она предлагает; `frely help --agent --json` выводит полный машиночитаемый контракт.
